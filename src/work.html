Homelab agentbash · python · claude code

An AI assistant for my homelab with ten scheduled jobs, from a morning briefing with weather, timetable changes, calendar, mail and parcels to a watchdog that checks the servers every five minutes and restarts failed services. It also answers questions in a private chat and through Siri.

I designed it so the model has no way to change anything directly. Small scripts fetch the data, each with an empty environment, only its own secrets file and a timeout. Their output counts as untrusted, and the model reads it in one call with no tools by default, then answers in a fixed JSON format. It can only propose actions from a whitelist per job, and every proposal waits for my approval on my phone, through buttons signed with HMAC. Only a few actions may run on their own, and those are rate-limited. Root access goes through two whitelisted helpers: one reads the system state, the other can only restart named containers. On the media server, its SSH key is locked to a single command. More than 350 tests keep these rules in place.
