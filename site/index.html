    An AI assistant for the homelab, built as a small plugin system. It writes a morning briefing (weather, school timetable changes, calendar, mail, parcels), checks the servers every five minutes and restarts failed services. It answers questions in a private chat and through Siri.

    Built security-first: scripts collect the data and the model only reads it, with no tools by default. Anything that changes the system is a whitelisted action that waits for my approval on the phone, with signed buttons and rate limits. More than 300 automated tests.
