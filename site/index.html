Selected work

Project River Zerodiploma thesis · unity · c#

A psychological horror game about hacking, made by four of us with equal shares and planned for release in spring 2027. My part is revelOS, the operating system the whole game takes place in. It has a virtual file system with owners and permissions, command processing, and SSH into other simulated machines. My thesis asks how to build a system like that so it stays easy to extend. I also built the project site, a replica of the revelOS desktop in Vue and three.js. You can try a small version of revelOS further down this page. project site ↗ · itch.io ↗

Homelab agentbash · python · claude code

An AI assistant for my homelab with ten scheduled jobs, from a morning briefing to a watchdog that checks the servers every five minutes and restarts failed services. I built it around one rule: scripts fetch the data and the model only reads it. Anything that changes a system waits for my approval on my phone, with signed buttons and rate limits, and more than 350 tests keep it that way.

Homelabdebian · docker · tailscale

Two Raspberry Pis and an old ThinkPad, running about 30 containers on a private tailnet: a media server, Pi-hole with Unbound, Home Assistant and Paperless. The one public exception is this site, which goes out through a Cloudflare Tunnel. Backups run every night, encrypted and off-site, on free tiers with hard caps. The media server has been in daily use for over a year.
